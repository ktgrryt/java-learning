# ☕ Java Café

Javaを手を動かしながら学べる、ローカル実行の学習アプリです。
解説とサンプルを読み、ブラウザ上でコードを書いて実行すると、自動採点されます。
基礎から業務開発、JVM、Web、運用、開発の工程まで、自分のペースで進められます。

## 必要なもの

- JDK 21以降（JREではなくJDK。最新security updateを推奨）
- Webブラウザ

Maven、Docker、npmはアプリ本体の起動には不要です。実ツールを使う章では、最初の
「事前確認」から必要な版、Docker daemon、ポートを確認できます。

```bash
javac -version
```

`javac 21`以上が表示されれば起動できます。JDK 21を使う場合は21.0.12以降を推奨します。
起動時に2026年7月CPUのbaseline（21.0.12 / 25.0.4 / 26.0.2）より古い版を検出すると
警告を表示しますが、学習アプリの起動とビルドは続行します。

## ダウンロード

Gitを使う場合は、次のコマンドで取得します。

```bash
git clone https://github.com/ktgrryt/java-learning.git
cd java-learning
```

GitHubの **Code → Download ZIP** からダウンロードし、展開したフォルダをターミナルで開いても構いません。

## 起動

```bash
./run.sh
```

必要なファイルが自動でビルドされ、ブラウザで `http://localhost:8123` が開きます。
終了するときは、起動したターミナルで `Ctrl+C` を押してください。

ブラウザを自動で開かない場合や、ポートを変更する場合は次のように起動します。

```bash
./run.sh --no-open
./run.sh --port 9000
```

## 基本的な使い方

1. 学習ホームで「続ける」、または好きな章を選ぶ
2. 解説と実行可能なサンプルを確認する
3. Javaコード、設定ファイル、複数ファイルのprojectを編集し、必要な章ではserver・DB・HTTP・JFR・containerも実際に動かす
4. クリア済みの問題は、あとから復習する

学習の進捗と書いたコード・設定ファイル・project/runtime-labの編集対象ファイルは `progress.json` に自動保存されます。
提出したJavaコードは自分のマシン上で実行されるため、出所の分からないコードは実行しないでください。

新しい版が公開されているかを、起動時にGitHubへ確認しに行きます（1日1回まで）。読むのは公開されている
版の番号だけで、進捗や書いたコードを送ることはありません。アプリがファイルを書き換えることもなく、
更新は `git pull` で行います。確認そのものは画面右上の ⚙ →「更新の確認」で切れます。切っているあいだ、
このアプリはどこへも通信しません。
