# ☕ Java Quest

手を動かしながらJavaを学ぶための、ローカルで動く学習アプリです。

1レッスンは **具体例つきの解説 → その場で実行できるサンプル → 練習問題** の3段構えになっています。
書いたコードを提出すると隠しテストを含む全ケースで自動採点され、全部通ると ★ が付きます。

**どのレッスンにもいつでも飛べます。** 順番のロックはかけていないので、気になる章から始めても、
分からなくなったら前の章に戻っても構いません。どこまで終わったかはサイドバーで一目で分かります。

画面は2つです。**メインメニュー**（起動時）と**レッスン画面**。

## 必要なもの

**JDK 17 以降だけ**です。Maven も npm も要りません（外部ライブラリを一切使っていません）。

```bash
javac -version    # javac 17.x 以上が出れば OK
```

入っていない場合は `brew install openjdk@17` などで入れてください。
JRE ではなく **JDK** が必要です（あなたのコードをコンパイルするため）。

## 起動する

```bash
./run.sh
```

ビルドしてサーバを起動し、ブラウザが自動で開きます（http://localhost:8123）。
終了は `Ctrl+C` です。

| オプション | 意味 |
|---|---|
| `./run.sh --port 9000` | ポートを変える（8123が埋まっていたら自動で+1して探します） |
| `./run.sh --no-open` | ブラウザを自動で開かない |
| `JQ_JAVA_HOME=/path/to/jdk ./run.sh` | 使うJDKを指定する（複数入れている場合） |

> JDKが複数入っている環境（Homebrew / sdkman / IDE付属など）でも動くように、
> `javac` と `java` は必ず同じJDKから使い、出力は JDK 17 でも動く形にしています。
> JDKを切り替えたときは自動でビルドし直します。

## 使い方

1. メインメニューで **▶ 続ける** を押す（または章カードを開いて好きなレッスンを選ぶ）
2. 解説を読み、**サンプルを実行**して動きを目で確かめる
3. エディタに自分でコードを書く
4. **▶ 実行してみる** … 採点せずに動かすだけ。気軽に試すためのボタン
5. **✓ 提出して採点** … 全テストケースで採点。全部通ると ★ が付く

**▶ 続ける** は、前回いたレッスンがまだ未クリアならそこへ戻り、
クリア済みなら次にやるレッスンへ進めます。

クリアしたレッスンには **★** が付いて文字がはっきりした色になり、まだのレッスンは
**○** と薄い色になります。章ごとに「2/4」のような進み具合とバーが出るので、
メニューでもサイドバーでも、どこまで終わったかがひと目で分かります。

| ショートカット | 動作 |
|---|---|
| `⌘/Ctrl + Enter` | 提出して採点 |
| `⌘/Ctrl + Shift + Enter` | 実行してみる |
| `Tab` / `Shift+Tab` | インデントする / 戻す |

書いたコードは自動保存されるので、ブラウザを閉じても続きから再開できます。

### 詰まったとき

**💡 ヒント** を押すと1つずつ開きます。全部開くと **📖 模範解答** が見られるようになります。
ヒントを使ってもクリア扱いになるので、遠慮なく使ってください。
ただし模範解答は写して終わりにせず、**1行ずつ「なぜそう書くのか」を自分の言葉で説明できるか**
試してみるのがおすすめです。

## カリキュラム（全20章 / 全90問）

**第1〜6章：文法のきほん**

| 章 | 内容 | 問 |
|---|---|---|
| 1 はじめてのJava | Hello World、`println` と `print`、コメント、文字と数のちがい | 3 |
| 2 変数と型 | `int` `double` `String` `boolean`、再代入と `final`、`+` の落とし穴 | 4 |
| 3 計算とキーボード入力 | 四則演算、整数の割り算の罠、`%`、キャスト、`Scanner`、`++` と `+=` | 5 |
| 4 条件で分ける | `if` / `else if`、比較演算子、`&&` `\|\|`、`equals`、`switch`、三項演算子と短絡評価 | 6 |
| 5 くり返す | `for`、合計をためる型、`while`、`break` / `continue`、二重ループ、`do-while` | 6 |
| 6 配列 | 宣言と添字、`length`、拡張for、最大値・最小値、2次元配列と `Arrays` | 5 |

**第7〜9章：メソッドとクラス（オブジェクト指向の入口）**

| 章 | 内容 | 問 |
|---|---|---|
| 7 メソッド | 引数と戻り値、`void` と `return`、オーバーロード、値渡し、可変長引数 | 5 |
| 8 クラスとインスタンス | `new` と参照、コンストラクタと `this`、フィールドの既定値、`==` と `null`、`static` | 5 |
| 9 カプセル化 | `private` とアクセサ、`final` と不変クラス、アクセス修飾子とパッケージ、総合問題 | 4 |

**第10〜13章：継承と例外**

| 章 | 内容 | 問 |
|---|---|---|
| 10 継承 | `extends`、オーバーライドと `@Override`、`super` とコンストラクタの連鎖、`toString` / `equals` | 4 |
| 11 ポリモーフィズムと抽象クラス | 親の型で受ける、キャストと `instanceof`、`abstract`、総合問題（図形） | 4 |
| 12 インターフェース | `implements`、多重実装、`default` と `static` メソッド、抽象クラスとの使い分け | 4 |
| 13 例外処理 | `try-catch`、`catch` の順序、`finally`、検査例外と `throws`、try-with-resources | 5 |

**第14〜17章：ライブラリを使いこなす**

| 章 | 内容 | 問 |
|---|---|---|
| 14 String と StringBuilder | 不変性、主要メソッド、`==` と `equals` と文字列プール、`StringBuilder`、総合問題 | 5 |
| 15 ラッパークラス | `Integer` などの対応、`parseInt` と例外、オートボクシングと `Integer` キャッシュ | 3 |
| 16 コレクション | `ArrayList`、ジェネリクス、`remove` の罠、`Map` で数える、`Set` と不変リスト | 5 |
| 17 ラムダ式 | 匿名クラスからラムダへ、`Predicate` と `removeIf`、4つの関数型インターフェース、`Comparator` | 4 |

**第18〜20章：モダンなJavaと総仕上げ**

| 章 | 内容 | 問 |
|---|---|---|
| 18 モダンな書き方 | `var`、switch式と `yield`、テキストブロック、`record`、`enum` | 5 |
| 19 日付と時刻 | `LocalDate` / `LocalDateTime`、不変性と月末の丸め、`Period` と `ChronoUnit`、`DateTimeFormatter` | 4 |
| 20 総仕上げ | `import static` とモジュールの概要、総合演習3問（在庫・単語集計・成績処理） | 4 |

テストケースは全564件で、そのうち **387件が隠しテスト**です。
`0`、負の数、境界値（「80点ちょうど」「残高とちょうど同じ額の出金」「`Integer` キャッシュの `127` と `128`」
「1月31日の1か月後」など）が仕込まれているので、たまたま通るコードではクリアできません。

> 第7章以降は **Java Silver（SE 17 / 21 相当）の出題範囲** をカバーしています。解説には
> `⚠️ 試験のワナ` として、試験で狙われる間違えやすい形を `✅` / `❌` の対比で載せました。
>
> ただし「このコードはコンパイルできるか」を問う4択形式は、提出コードが通ることを前提にした
> 採点方式のため作れていません（解説内の対比で扱っています）。同じ理由で、パッケージを跨いだ
> `protected` の可視性と `module-info.java` も解説どまりです。

> 第1章・第2章と `3-1` `6-1` は入力を受け取らない問題なので、出力が1通りに決まります。
> そのためこれらのレッスンには隠しテストがありません。`3-2` 以降は入力が変わるので、
> 隠しテストで「どんな入力でも正しく動くか」が試されます。

## コンテンツを追加・修正する

レッスンは `content/*.json` に入っています。**Javaコードを触る必要はありません。**
編集してブラウザを再読み込みすれば、すぐ反映されます（サーバの再起動も不要です）。

### レッスンを1つ足す

`content/ch04-branch.json` の `lessons` 配列に、次の形で追加します。

```json
{
  "id": "4-7",
  "title": "レッスンのタイトル",
  "explanation": "## 見出し\n\n解説をマークダウンで書く。\n\n```java\nint n = 1;\n```",
  "samples": [
    { "caption": "動かしてみよう", "code": "public class Main { ... }", "stdin": "" }
  ],
  "task": "練習問題の説明（マークダウン）",
  "starterCode": "public class Main {\n    public static void main(String[] args) {\n    }\n}\n",
  "visibleCases": [
    { "label": "5 のとき", "stdin": "5", "expected": "答え" }
  ],
  "hiddenCases": [
    { "label": "0 のとき", "stdin": "0", "expected": "別の答え" }
  ],
  "hints": ["1つ目のヒント", "2つ目のヒント"],
  "solution": "public class Main { ... }"
}
```

| キー | 説明 |
|---|---|
| `id` | レッスンID。画面に出るので `4-6` のような形にします。全体で重複しないこと |
| `explanation` | 解説。マークダウン（見出し・箇条書き・表・引用・コードブロック）が使えます |
| `samples` | 解説中の「▶ サンプルを実行」ボタン付きコード。`stdin` は省略可 |
| `starterCode` | エディタの初期状態 |
| `visibleCases` | 提出前から見えるテストケース（問題の仕様として見せるもの） |
| `hiddenCases` | 提出するまで隠れているテストケース。**失敗したケースだけ中身が開示されます** |
| `hints` | 上から順に開示されます。全部開くと `solution` が見られるようになります |
| `solution` | 模範解答 |

**判定は「出力の完全一致」です。** ただし各行の行末の空白と、末尾の空行は無視されます
（初心者がつまずきやすく、学習の本題でもないため）。

### 章を1つ足す

1. `content/ch21-xxx.json` を作る（既存のファイルを写すのが早いです）
2. `content/manifest.json` の `chapters` にファイル名を足す

章の番号は `manifest.json` の並び順から自動で振られます。

### 追加したら検証する

```bash
./tools/verify-solutions.sh
```

全レッスンについて次を確認します。

- `starterCode` がコンパイルできるか（ひな形が壊れていないか）
- `samples` のコードが実行できるか（解説に載せたコードが動かないのは最悪なので）
- `solution` が **全テストケースを通るか**

コンテンツを直したら毎回これを走らせてください。進捗ファイルは書き換えません。

画面右上の「進捗リセット」を押すか、`progress.json` を削除してください。

## コードの実行について

提出したコードは、あなたのマシン上で **別のJavaプロセス** として実行されます。
暴走しても学習が止まらないよう、次の制限をかけています。

- 実行時間 **5秒**（超えたら強制終了して「終わらないループかも」と表示）
- メモリ **256MB**
- 出力 **20,000バイト**（超えたら打ち切り）
- サーバの待ち受けは **127.0.0.1 のみ**（同じネットワークの他人からは触れません）

とはいえ「自分の書いたコードが自分のマシンで動く」ことは変わりません。
インターネットで拾ったコードをそのまま提出するのは避けてください。
