# パッケージ境界演習

Java基礎編『カプセル化』のレッスン「アクセス修飾子とパッケージ」が採点に使います。

**1つの画面で複数のファイルを扱う、基礎編で最初の演習です。** 必要なのはJDKだけで、
Maven・Docker・ネットワークは要りません。ターミナルを開く必要もありません
（提出すると、アプリが `javac` でまとめてコンパイルして確かめます）。

「4段階の見える範囲」を表で覚えるのではなく、**通ってはいけないコードが本当に通らない**ことを
確かめる演習です。見える範囲は動かしても分かりません（見えなければコンパイルが止まるので、
実行までたどり着けません）。そこで、通ってはいけないコードを `probe-*/` に置いてあります。

## ファイル

| ファイル | 役割 |
|---|---|
| `src/cafe/shop/Item.java` | **編集する。** 商品1つ。見える範囲をここで決める |
| `src/cafe/menu/SeasonalItem.java` | **編集する。** 別パッケージにいる `Item` のサブクラス |
| `src/cafe/shop/Stock.java` | 参照専用。`Item` と同じパッケージなので在庫を減らせる |
| `src/Main.java` | 参照専用。出力を作る |
| `probe-package-private/`, `probe-subclass/`, `probe-protected/`, `probe-field/` | 参照専用。**コンパイルできてはいけない**コード |
| `reference/` | 模範解答（画面には出ません） |

## 採点で何が起きるか

`./run-tests.sh` が6つを見ます。**4つは「コンパイルできないこと」**の確認です。

| 見るところ | 直っていないとき | 直ったとき |
|---|---|---|
| `src` をまとめてコンパイル | 見せるべきものが足りない／広すぎる | 通る |
| `Main` の出力 | `???` のまま | `春の さくらラテ x5` などが出る |
| `probe-field`（同じパッケージから `stock` を読む） | 修飾子なしなので**読めてしまう** | `private` なので通らない |
| `probe-package-private`（別パッケージから `reduce`） | `public` なので**呼べてしまう** | 修飾子なしなので通らない |
| `probe-subclass`（別パッケージのサブクラスから `reduce`） | `protected` だと**呼べてしまう** | 修飾子なしなので通らない |
| `probe-protected`（サブクラスでない別パッケージから `label`） | `public` だと**呼べてしまう** | `protected` なので通らない |

## 手元で動かす

```bash
cd labs/basics/package-boundary-exercise
./run-tests.sh              # いまの src/ を検査する（最初は失敗します）
./run-tests.sh reference    # 模範解答を重ねて検査する（すべて通ります）
```

`src/` は書き換えても構いません（画面から提出する内容とは別です）。
