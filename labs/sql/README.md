# SQLラボ

`schema.sql` はH2 2.xとPostgreSQLで試しやすい標準寄りのSQLです。ローカルの
練習用DBへ適用し、末尾のSELECTを実行してください。本番DBへは適用しないでください。

確認すること:

1. 存在しない顧客IDの注文をINSERTし、外部キー違反になること
2. 負の金額をINSERTし、CHECK制約違反になること
3. 集約SELECTを`EXPLAIN`し、データ量を増やす前後で計画を比べること
4. `status, created_at` の複合インデックスを追加し、代表SQLで効果を測ること

DB製品ごとに実行計画や日時・自動採番の構文は異なります。使う製品の公式文書も
合わせて確認してください。
