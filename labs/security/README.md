# パスワード保存ラボ

JDK標準のPBKDF2を使う最小例です。実運用では組織のセキュリティ要件に従い、
Argon2idなど利用環境で推奨される方式、パラメータ、秘密管理を選んでください。

## 必要なもの

- JDK 21以降のみ

> JDK 21.0.8 (IBM Semeru) / macOS 15 で動作確認

## 手順

```sh
javac PasswordHasher.java
java PasswordHasher
```

## 成功したらこう出る

```
stored-prefix=pbkdf2-sha256
correct=true
wrong=false
```

正しいパスワードは一致し、誤ったパスワードは一致しません。

## 確認すること

1. 保存文字列には方式、反復回数、salt、導出値が入り、**平文パスワードは入らない**
2. 同じパスワードでも保存文字列が毎回変わる（saltが毎回違う）。2回実行して見比べる
3. 反復回数を増やすと1回の検証にかかる時間が増える。上げたときの移行のしかたは
   アプリ内のレッスン「認証情報と段階的アップグレード」で扱っています
